# بازگردان

صفحه معرفی افزونه ووکامرس «بازگردان» — بازیابی خودکار سفارش‌های ناموفق.

این مخزن فقط صفحه پیش‌نمایش است و روی GitHub Pages منتشر می‌شود.
خود افزونه از طریق ژاکت فروخته و پشتیبانی می‌شود.

- `index.html` — صفحه اصلی
- `guide.pdf` — راهنمای کامل نصب و تنظیم
- `assets/` — تصاویر و فونت‌ها

برای تغییر لینک دکمه‌های خرید، در `index.html` مقدار `BUY_URL` را عوض کنید.
